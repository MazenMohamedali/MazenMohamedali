## 🚀 Featured Project

### [VendorHub](https://github.com/MazenMohamedali/VendorHub) — Enterprise Multi-Vendor E-Commerce Platform

![ASP.NET Core](https://img.shields.io/badge/ASP.NET%20Core-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![C#](https://img.shields.io/badge/C%23-239120?style=flat-square&logo=csharp&logoColor=white)
![SQL Server](https://img.shields.io/badge/SQL%20Server-CC2927?style=flat-square&logo=microsoftsqlserver&logoColor=white)
![Redis](https://img.shields.io/badge/Redis-DC382D?style=flat-square&logo=redis&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)

A production-oriented multi-vendor e-commerce backend built around Clean Architecture and SOLID principles.

- Two-level **L1/L2 caching** (IMemoryCache + Redis) with event-driven invalidation — cut response times from **372ms to ~1.88ms** on cache hits (~200× faster, verified via Seq)
- Real-time order/admin notifications over **SignalR**, with claims-based, fine-grained vendor permissions
- Async background processing via an in-memory event queue to keep notification work off the request path
- Repository + Unit of Work patterns, optimistic concurrency, RFC 7807 `ProblemDetails`, global exception handling
- Image upload security via magic-byte validation + WebP compression
- Containerized with Docker Compose; growing an xUnit test suite alongside development
